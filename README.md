# RIDI 키워드 제외 검색 (Chrome Extension)

RIDI 키워드 검색 페이지에서 **특정 태그를 제외 목록에 등록**하고, 검색 결과에 즉시 반영할 수 있도록 돕는 크롬 확장프로그램입니다.

---

## 1) 설치 방법

### 1-1. 이 레포를 ZIP으로 다운로드
1. 이 GitHub 페이지에서 **Code** 버튼 클릭
2. **Download ZIP** 클릭
3. 다운로드한 ZIP 파일을 **압축 해제**합니다  
   - Windows: 우클릭 → “압축 풀기”
   - Mac: 더블클릭

### 1-2. 크롬에 확장프로그램 설치
1. 크롬 주소창에 `chrome://extensions`를 입력하고 이동합니다.
2. 오른쪽 상단 **개발자 모드**를 켭니다.
3. 왼쪽 상단 **압축해제된 확장 프로그램을 로드** 버튼을 클릭합니다.
4. 2-1에서 압축 해제한 폴더(`RIDI-EXCLUDE-TAGS`)를 선택합니다.
5. 설치가 완료되면 확장프로그램 목록에 나타납니다.

## 2) 사용 방법

1. 리디 키워드 검색 페이지를 엽니다.
- 예: `https://ridibooks.com/keyword-finder/` 로 시작하는 페이지
2. 크롬 우측 상단 확장프로그램(퍼즐 아이콘)에서  
**리디 제외 검색**을 클릭해 팝업을 엽니다. 고정 시켜두면 더 편하게 사용하실 수 있습니다.
3. 팝업 화면에서
- **제외 모드**: 제외 모드를 체크한 뒤 태그를 클릭하면 검색 제외 목록에 저장됩니다.
- **제외 목록**: 마우스를 올리면 태그를 제거할 수 있습니다.
- **검색 반영**: 검색 반영이 되지 않았을 때 클릭하면 즉시 반영합니다.
- **전체 삭제**: 제외 태그를 모두 지울 수 있습니다.
