# 리디 검색 도우미

리디 키워드 검색 결과를 모아 제외 태그가 없는 작품만 보여 주는 크롬 확장 프로그램이에요.

---

## 1) 설치 방법

### 1-1. 이 레포를 ZIP으로 다운로드
1. 이 GitHub 페이지에서 **Code** 버튼 클릭
2. **Download ZIP** 클릭
3. 다운로드한 ZIP 파일을 **압축 해제**합니다  
   - Windows: 우클릭 → “압축 풀기”
   - Mac: 더블클릭

### 1-2. 크롬에 확장프로그램 설치
1. 크롬 주소창에 `chrome://extensions`를 입력하고 이동합니다.
2. 오른쪽 상단 **개발자 모드**를 켭니다.
3. 왼쪽 상단 **압축해제된 확장 프로그램을 로드** 버튼을 클릭합니다.
4. 1-1에서 압축 해제한 폴더(`ridi-exclude-tags`)를 선택합니다.
5. 설치가 완료되면 확장프로그램 목록에 나타납니다.

## 2) 사용 방법

1. 리디 키워드 검색에서 포함 태그를 골라요.
2. 확장 프로그램의 **리디 검색 도우미** 팝업에서 **제외 모드**를 켜고, 빼고 싶은 태그를 눌러요.
3. 목록이 제외 반영 결과로 바뀌어요. 결과 개수와 페이지 수도 함께 바뀌어요.
4. 제외 태그는 저장되어 다른 검색에도 계속 적용돼요.

- **도우미 켜기**를 끄면 리디 원래 목록으로 돌아가요.
- 제외 태그에 마우스를 올리고 누르면 지울 수 있어요. **전체 삭제**로 모두 지울 수 있어요.
- 포함 조건과 겹치는 제외 태그는 무시해요.
- 제외 모드를 끄면 태그를 눌러 포함 조건에 넣을 수 있어요.

검색 결과는 현재 정렬 순서의 상위 3,000개까지만 거릅니다.

리디 비공식 확장 프로그램이며 개인 용도입니다.
